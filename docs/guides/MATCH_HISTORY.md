# 本地对局记录

从此版本开始，玩家收到 `m.result` 结算消息后自动保存到浏览器 IndexedDB（`stronghold-match-history`）。保留最近 100 局，按服务器结算时间倒序排列。首页、大厅和结算页面的「对局记录」按钮均可打开历史。

记录包括版本、种子、模式、难度、开始/结束时间、耗时、胜负、通过回合、领袖与隐秘核心状态，以及各成员的最终阵容、装备、盟约、伤害和其他结算统计、称号、奖励。详情复用结算成员卡片，导出的 JSON 保留棋盘坐标和装备 ID 等完整快照字段。

服务器结算消息新增稳定的 `matchId`、`startedAt`、`finishedAt`，断线重连重复推送同一局时不会新增记录。兼容旧服务器没有 `matchId` 的结算消息，使用种子、模式、关卡、耗时和成员 ID 去重。观战者不保存个人战绩；队友通关但自己提前淘汰时，列表按本人的胜负与通过回合展示。

记录仅保存结算数据，不记录逐帧战斗或每回合操作，无法播放完整录像。存储操作只发生在结算、历史查看、导入和用户删除时，不在战斗循环中写盘。数据库不可用或存储额度不足时会显示保存失败，正常结算继续进行。不会保存身份令牌、连接凭据或实时会话对象。

## 数据管理

- 「导出本局 / 导出全部」下载格式为 `stronghold-match-history`、schema 为 1 的 JSON 文件，可用于备份与排查问题。
- 「导入记录」可选择本游戏导出的 JSON 文件（最大 16 MB），与当前浏览器的记录合并，跳过重复记录，并保留结算时间最新的 100 局。支持恢复已经删除的记录，也可把备份迁移到其他浏览器或站点；导入不会改变备份中的原始站点和版本信息。
- 导入前会检查整份文件，格式或记录无效时不做任何改动；写入使用单次事务，存储失败不会留下部分导入的数据。
- 删除本局和清空操作需要页面内确认；保留少量无结算内容的去重标记，防止重连推送把已删除的记录重新加回来。这些标记也有数量上限。
- 同站点多标签页由数据库事务避免重复写入；历史窗口通过 BroadcastChannel 接收其他页面的更新。
- 浏览器、设备或域名不同，记录分别保存。`localhost`、国内站与香港站不会共享本地记录。清除网站数据、浏览器自动清理存储、无痕窗口关闭等会导致记录消失。该功能不会把历史上传到服务器。
- 更新之前的对局没有本地记录，无法补回。

## 验证

`node --test test/history/record.test.js test/match/results.test.js` 检查快照字段、凭据过滤、成员资格、旧服务器去重、导入导出格式和结算身份稳定性。

Windows PowerShell：`$env:HISTORY_E2E='1'; node --test test/history/browser.e2e.test.js`。默认使用本机 Edge，可通过 `CHROME_PATH` 指定 Chrome / Edge。浏览器测试启动独立临时端口，验证真实 WebSocket 自动保存、重载保留、去重、100 局上限、多个写入方、跨标签更新、删除后重连、文件导入、无效文件拒绝，以及首页关于弹窗和按钮布局。
