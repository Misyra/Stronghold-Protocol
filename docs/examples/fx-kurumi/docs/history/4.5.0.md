# 4.5.0：5元本金、个人结算、留存管理费与金额风险

维护者要求：每轮本金上限5元，移除担保人与相关代码，每留存5元扣1元，难度由金额×倍率决定。
删除委任窗口/卡片/标记物、绑定、队友垫付、偿还队友和信用额度设置。亏损仅扣本人现金和新回合收入。
[ASSUMED] 个别资金不足（例如房主开启3倍）保留本人待补亏损，由后续收入补足，不能免债或转嫁队友。
管理费在onIncome、当期收入与pending到账前按留存现金floor(/5)收取，不对新收入和当期返款重复征费。
本金1～5元，难度以实际本金×倍率的1～15区间插值原回合曲线；相同乘积同种子结果相同，保留低档分支及上限。
原生quote允许省略整组信用counter字段，纯现金报价正确预览；有信用字段的旧插件仍要求完整合法的一对。

验证结果：作者测试30/30，原生报价/守卫41/41，真实Edge交互通过；覆盖留存5元分档收费、
新收入与pending不收费、同乘积同结果、资金不足按实际本金定难度、同目标取最高乘积、
默认5×2收入补足亏损、3倍极端亏损不免除、队友余额不变。291个原版黄金结果一致。
