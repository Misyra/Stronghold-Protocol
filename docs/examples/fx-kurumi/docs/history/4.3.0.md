# 4.3.0：挑战难度与悬赏金币分离

> 已由 [4.3.1](4.3.1.md) 修正：当时误把原始lpr当作普通回合扣血依据，以下排除规则及相关理由已废止。普通回合每只有效漏怪计1，原排除的5种现已全部恢复。

原先按击杀金币分池，导致第4回合就可能抽到2金的家族暗影灭迹人，1金池也包含低价Boss。
现在以独立人工表归档56种来源敌人，其中51种入池、5种排除；暗影灭迹人归4级，正常第4回合不再出现。

来源为当前仓库默认版的官方生成数据及现有模拟技能实现 `data/choices.json` 与 `data/enemies.json`；未修改这些文件。
等级和排除项均为插件自定义决定 **[ASSUMED]**，不是官方战力评价或统计胜率。
完整规则及逐项理由见[当前分级](../design/enemy-grades.md)。

保留倍率与回合权重曲线、独立10%低等级分支、后期最高等级54%上限、仓位和对称金额结算。
房间设置键weight1～weight5保留，文案和含义改为挑战等级。跨金币重复敌人按ID全局去重，模式禁用仍生效。
未知敌人、零扣血或扣血超过5的敌人不入池；空池或添加失败退本金。

验证项：严格插件检查、打包、作者测试（分级覆盖、逐池抽取、各模式可用性、早期禁出高等级、6000种子分布、真实SES加载及完整生命周期）；
另运行仓库文档一致性与路径检查。结果见交付说明。核心模拟与官方玩法未改，无黄金场景变动。
