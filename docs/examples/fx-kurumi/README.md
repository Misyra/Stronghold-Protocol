# 久留美：保证金交易 4.5.3

每个普通回合可下注一次或观望，随机目标可能是自己；Boss和隐秘核心休市。
直接选择1～5元，**每轮实际本金最多5元**；余额不足按实际余额缩减。
房间倍率上限默认2倍，房主可调1～3倍。押对净赚、押错净亏 `round(实际本金×倍率)`。
默认5元×2倍最多净盈亏10元，房主提高到3倍后最多15元；本金返还、收入和管理费另计。

## 留存管理费

每回合收入到账前，按上回合仍在账户中的现金收取 `floor(留存现金/5)` 元：
0～4免收、5～9收1、10～14收2、25收5。当前回合新收入、待到账战利品和随后结算的交易返款不计入本次收费。
已划扣的合约本金暂不在账户现金中；返款若继续留存，会在下回合收费。替换旧的10元档财富税，不叠加收费。

## 个人结算

没有保证人委任、队友垫付或信用额度设置。所有净亏损仅由玩家本人承担。
本金建仓时先划扣，下回合收入到账后再结算本金之外的亏损；余额仍不足时，保留“待补亏损”，后续收入优先补足。
例如第1回合5元×2倍押错，5元本金已扣，下回合5元收入足够补剩余5元，不动队友的钱。
房主提高倍率或其他特殊收入变化时，也不会把未付亏损免除。内置面板仅在需要时显示待补亏损。

## 每轮挑战与难度

每名存活久留美仅在成功下注后向随机目标追加1名挑战敌人，不额外掉金币。
观望、超时跳过和资金不足未建仓都不追加；普通回合原有敌人及留存管理费照常。
多人游戏中，观望玩家仍可能成为另一名下注者抽中的目标。
同一目标只出1只，多个持仓取最高的**实际本金×倍率**，不把不同玩家的金额相加。
用余额不足时缩减后的实际本金计算，不用按钮上的申请额。方向不影响抽敌；同乘积、同种子抽取相同。
未下注不触发挑战。难度系数 `clamp((实际本金×倍率−1)/14,0,1)`，乘积1～15对应原回合曲线的两端。

## 界面、安装和验证

保证金面板随主插件提供，无需另装界面插件。新规则需刷新页面并新开对局，不热改进行中的比赛。
`node tools/plugin.mjs check fx-kurumi --strict`、`node tools/plugin.mjs pack fx-kurumi --zip`、
`SP_PLUGIN_SCRIPTS=sandbox node tools/plugin.mjs test fx-kurumi`。

以上为维护者要求的插件自定义平衡[ASSUMED]，没有修改官方模拟规则。

## 默认生命与启用

初始生命20。服务器通过 `npm run start:plugins` 允许沙盒插件；房间默认不选插件，由房主在插件面板手动启用。

## 仓库源码安装

在仓库根目录运行 `npm run kurumi:install`，再运行 `npm run start:plugins`。
首次安装使用现有插件安装器的ZIP校验；同名插件存在时拒绝覆盖，可先自行备份并用安装器的 `--force` 更新。
源码目录不含角色图片，图标引用本安装的坎诺特素材；本机已有的自定义图片不受影响。
作者测试在安装到 `plugins/fx-kurumi` 后运行，测试中的根目录相对引用遵循安装布局。

## 净余额与补扣提示（4.5.3）

面板净余额＝可用现金−待补亏损，可以为负数；有未补亏损时同时列出现金与欠款。
可用现金仍最低为0，欠款不免除：后续回合补扣现金、收入或待到账款时会提示本次补扣及尚欠金额。
例如5元×3倍押错且无余款，下回合收入5元后净余额为−5；再下回合收入6元，补扣5元后剩1元。
抽怪概率未改：前4回合5元×2倍时，1/2/3级分别约30.36%/40%/29.64%；等级概率不等于漏怪率。
