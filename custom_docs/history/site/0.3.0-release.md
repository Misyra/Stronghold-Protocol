# 0.3.0 更新日志

2026-10-16 · 上游同步至 v0.3.0（原定 0.2.7 的修复一并并入）

一句话：这次最重要的更新是**插件系统**——服务器可以装插件，外观、数值、新干员、界面小组件都能换；此外官方特效、场景光照和一大批规则都按官方重做了。

## 插件（新）

- 服务器装好插件后，房主在房间顶部的「原版 / 插件 ×N」面板里为整个房间开启。不选插件就是原版玩法。
- 改变玩法的插件对局标为「非官方」，统计总览默认不计入（可用「含插件对局」查看）；只开外观插件仍算原版对局。
- 数据插件能改数值、经济与波次，添加干员、敌人和新模式；外观插件能换头像、立绘、模型、图标、语音、音效与音乐；界面插件在对局里显示伤害统计这类小组件，每位玩家自己开关。
- 插件工作台 `/studio/`：在浏览器里选模板、拖素材、实时预览、一键打包下载；「试一场」可以并排对照原版与插件。
- 支持导入 Forge 工坊包（先看转换报告）、安装插件 zip 或按地址安装、从社区目录挑选。
- 脚本插件默认关闭，要服主开启沙箱才会运行。

## 画面

- 设置新增「官方特效」（关 / 精简 / 完整，默认电脑完整、手机精简）：用本机客户端提取的官方特效绘制普攻出手、弹道、命中、治疗、异常状态、阵亡、部署、技能与天赋，以及敌人技能和阻挡近战。
- 官方场景按客户端着色器重新打光（并补上反射、高光与法线），11 个战场的素材已重提，场景不再偏暗；水面按这张图自己的水材质绘制。
- 射击台改用官方模型绘制（金属高台，干员站在台面上）。
- 3D 棋盘的出怪口与目标点方框按客户端粒子着色器上色：红框纯红、蓝框浅青，不再像在发光。
- 休整期和官方一样，下一回合的敌人站在棋盘右上方的预览区里，点 🔍▶▶ 镜头平移过去。
- 拖起干员、装备或召唤物准备部署时，商店临时收起、棋盘放大（松手或部署完恢复）。

## 规则（按官方）

- 攻击判定：出手时目标还在射程内，这一下会追着目标打完；敌人开始攻击后目标走出射程也会打完，晕眩等控制仍能打断。
- 射程按敌人的碰撞箱判定（碰撞圈压到射程格就能被索敌和攻击）。
- 伊利昂的木驮兽和「越长尘」会载客：把身边的非领袖、非机械地面敌人装为乘客，被击倒或进蓝门时放下。
- 冻结商店后手动刷新会取消冻结（钱不够等刷新失败则不变）。
- 商店里已经出现过的装备，库存被别人拿空后仍然可以买；已出现的装备奖励也仍可领取，多出的份数记为欠账。
- 临时整备区超过 5 个可见格时，多出来的干员与装备会排队保留，空出位置后自动补进。
- 晋升奖励、定向投放、见者有份等奖励没选会一直保留到选下为止，不再在休整期结束时消失。
- 一批干员修正：枯朽之种自毁改为弹道、假想敌：镜膜被沉默后永久失去生命值加成、风丸替身可以打空中、瑕光二技能能打四周的沉睡敌人、贾维赠送能在首次刷新时凑齐三只拉普兰德、维多利亚攒够 25 层在盟约激活时立即发锤。
- 机器人改进：孤立的重卫移到队友火力能覆盖的路径格，有阻挡的医疗优先站路径外，采购按实际手牌容量算阵容，演习按真实的开战输入评估布阵。

## 界面与操作

- Q / X 改为对鼠标指向的己方干员撤退 / 出售（整备区与临时整备区也可出售），新增默认 W 悬停购买商店卡；可改键。
- 干员语音增加 English / 한국어 与本土语言配音；干员调配和自选详情里可以给单名干员单独选配音并试听。
- 统计页向官方统计页靠拢：获得奖杯、独立 / 联合模拟两行、六称号六边形图、单局纪录、「盟约 & 策略」页。
- 设置新增「作战统计」「秘术师能量」「弹药数量」等可选项（默认关闭，只在本机显示）。
- 标题画面并排「下载完整素材」与「导入素材包」两个按钮，导入不上传、只收下和服务器清单哈希一致的文件。
- 整站默认启用内容安全策略（CSP）。

## 本站自有（官方之上）

- **官方皮肤**：174 名干员 / 273 套官方时装，可替换局内模型（队友看得见）与商店立绘（只在本机）。
- **作战统计面板**：设置里默认开启，对局左下角看自己干员的伤害、治疗与 DPS / HPS。
- **全新大厅 / 房间 / 结算界面**：程序化大厅背景、结算个人战报与同盟评级、房间座位卡与名片干员。
- **手机端优化**：管理界面密度、横屏适配与房间顶栏排版重做，小屏不再挤成一团。
- **资源预载面板重做**：必备与可选一屏看清，可一并预载官方特效与皮肤，支持 ZIP 导入导出与断点续传。
- **维护公告支持远程中心源**：可由运维统一发布、按间隔热更新，断源时保留最后一条。
