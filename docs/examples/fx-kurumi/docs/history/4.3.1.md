# 4.3.1：恢复全部候选敌人并下调部分挑战等级

修正4.3.0误用原始lpr的错误：普通回合按有效漏怪条目数量扣血，每只1，默认每轮上限10；联防按归属统计最终剩余数量。
依据为 `server/match/match/settle.js` 和 `server/match/unite.js`，不是敌人原始lpr字段。
鸭爵、高普尼克、流泪小子、圆仔、墓碑全部恢复入池。

按用户要求，第4级下放2种至第3级：大鲍勃、尖端萨卡兹枯朽战车；第5级下放2种至第4级：温顺的武装大驮兽、遗弃者。
最终1～5级数量为1、3、11、24、17（模式禁用前），合计56种。
默认3倍第4回合3级概率从40%降到35%，第8回合5级从10%降到7.5%，后期5级最终从54%降到49.5%；低等级合计14.5%。
这只降低倍率造成的难度偏移，不改变自选方向、目标抽签与结算，不保证消除主动漏怪或串通的影响。

原先按击杀金币分池，导致第4回合就可能抽到2金的家族暗影灭迹人，1金池也包含低价Boss。
现在以独立人工表归档56种来源敌人，全部恢复入池，按普通回合计数规则归档；暗影灭迹人归4级，正常第4回合不再出现。

来源为当前仓库默认版的官方生成数据及现有模拟技能实现 `data/choices.json` 与 `data/enemies.json`；未修改这些文件。
等级为插件自定义决定 **[ASSUMED]**，不是官方战力评价或统计胜率。
完整规则及逐项理由见[当前分级](../design/enemy-grades.md)。

保留回合权重曲线，将倍率增难幅度降低25%；保留独立10%低等级分支、后期最高等级54%上限、仓位和对称金额结算。
房间设置键weight1～weight5保留，文案和含义改为挑战等级。跨金币重复敌人按ID全局去重，模式禁用仍生效。
未知敌人或不计入有效漏怪的敌人不入池，原始lpr不作为筛选依据；空池或添加失败退本金。

验证项：严格插件检查、打包、作者测试（分级覆盖、逐池抽取、各模式可用性、早期禁出高等级、6000种子分布、真实SES加载及完整生命周期、5种恢复敌人的实际漏怪记录和每只扣1血的正常回合结算）；
另运行仓库文档一致性与路径检查。结果见交付说明。核心模拟与官方玩法未改，无黄金场景变动。
