# 久留美 4.5.1：挑战敌人分级

本表是插件自定义平衡 **[ASSUMED]**，不是官方难度或金币定价。
来源：仓库默认版本的 `data/choices.json`（悬赏记录）与 `data/enemies.json`（基础面板与能力），并复核当前模拟技能实现，特别是变形、分裂和不可阻挡机制。
运行时唯一分级表是 `meta.js` 的 `CHALLENGE_RATINGS`；本表逐项列出其理由。

## 当前规则（4.5.1）

仅成功下注才向随机目标追加挑战；观望/超时跳过/无钱未建仓均不触发。
实际本金最多5元，默认倍率上限2倍、房主可调1～3倍；难度概率由回合与实际本金×倍率共同决定。
把乘积1～15归一化为 `clamp((本金×倍率−1)/14,0,1)`，插值原先低/高风险回合曲线。
同乘积、同回合、同种子得到同一敌人；资金不足时按实际缩减本金计算，方向不影响抽敌。
同一目标多个久留美不叠怪，取最高乘积。默认5元×2倍的乘积10，不等同于单独看2倍。
56种分级、10%低等级分支、房间权重、5级最终54%上限保留；前4回合不出4～5级。
Boss/隐秘核心不追加挑战，不额外掉挑战金币。分级不是统计胜率，下表逐项理由保留。

## 后续校准

优先观察每档在相同地图、模式、回合与参考阵容下新增的有效漏怪率，以及前排死亡、控制和召唤造成的间接影响。
按敌人逐项升降级，不把单次抽中或单局胜负当作概率出错。当前验证覆盖分级接线、确定性及池可用性，并非完整阵容的多空胜率标定。
